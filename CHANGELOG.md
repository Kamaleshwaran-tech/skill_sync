## [0.2.0] - 2026-10-07

This is the first feature-complete release of SkillSync AI, a student career-readiness platform
that parses resumes, analyzes skill gaps against target roles, and generates AI-powered learning
roadmaps.

### Added
- **Dashboard as the central hub**: After login, the Dashboard now surfaces the full career picture in one place:
  - Resume-derived profile summary (name, contact, experience/project/education counts, parse-quality score, detected skills).
  - **Target role input** (persisted per user) — e.g. "Full Stack Developer", "Data Scientist".
  - **Skill-gap analysis** — missing skills prioritized HIGH / MEDIUM / LOW against jobs matching the target role.
  - **AI learning roadmap** — sequenced learning steps, suggested projects, certifications, and career advice generated by Gemini.
- New backend dashboard endpoints:
  - `GET  /api/v1/dashboard` — combined profile + target-role + resume + recommended-jobs payload.
  - `GET  /api/v1/dashboard/target-role` — read the user's saved target role.
  - `POST /api/v1/dashboard/target-role` — save/update the target role.
  - `POST /api/v1/dashboard/analyze` — run skill-gap + AI roadmap analysis for the saved role.
- `POST /api/v1/dashboard/analyze` returns helpful 400 errors when a resume or target role is missing.
- Role-specific skill dictionary fallback so the skill-gap analysis works even before jobs are ingested.
- Resume-upload success screen now sends users to the Dashboard (the new primary CTA) instead of the analysis page.

### Changed
- **Removed standalone Career Readiness page** entirely (route `/career-readiness`, nav item "Readiness", and component imports) — its functionality now lives on the Dashboard.
- Slimmed the `DashboardResponse` schema to remove legacy readiness/careerMatches/skillDemand/learningProgress/recommendedProjects/certifications/recentActivity builders and replaced them with the resume/target-role/analysis model.
- Frontend `dashboardService` extended with `getTargetRole`, `setTargetRole`, and `runAnalysis` (180s timeout for AI generation).

### Fixed
- Resume upload "timeout of 10000ms exceeded" error:
  - Increased client-side upload timeout to 180s.
  - Reworked embedding and resume analysis to run faster and not block the upload response.
  - Raised server-side analysis/parsing timeouts.
- Resume-file reads use `seek(0)` so the file handle is not consumed before the parser runs.
- Invalid MUI icon import (`WorkOutline`) that caused a blank screen on the Dashboard.

### Technical
- React 19 + Vite 8 + MUI 9 frontend.
- FastAPI backend with SQLAlchemy, SQLite (dev), Alembic migrations.
- Gemini (Google AI) for LLM-powered resume parsing and roadmap generation.
- Adzuna integration for real job matching.
- JWT-based auth with refresh tokens.
